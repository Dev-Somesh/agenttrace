# Sample agent — explore, then stop

An agent definition is a specialised role: what it may touch, what it must
return, and when it should hand back. This one is a reader, not an editor.

## Role

Map a directory and report what is there. Do not edit.

## Tools

Read, search, list. No writes.

## Return

A short list of paths and one sentence each on what they are for. If the
directory is empty, say so and stop.
