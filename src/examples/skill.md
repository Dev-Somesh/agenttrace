# Sample skill — read before you rewrite

A skill is a short instruction a runner loads for a job it will do more than
once. runlanes shows the copy so you can see what it was told, not what it
claims it did.

## When to use this

Before changing a file the runner has not opened in this session.

## Steps

1. Open the file. Confirm the name and the surrounding code.
2. Change only what the current task needs.
3. Leave comments that were already there unless they are now false.

## Do not

- Invent a helper that exists two folders away.
- "Clean up" while you are there.
