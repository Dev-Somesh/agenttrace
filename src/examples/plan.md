# Sample plan — ship a measured console

A plan is a written approach, not a transcript. runlanes renders it so you
can read what was decided without opening the runner's folder.

## Goal

A local page that answers three questions from files already on disk: what
the run cost, whether it overlapped, and which files it touched.

## Constraints

- Every number is measured from a transcript, not reported by the agent.
- Nothing leaves the machine.
- A runner the product has never heard of must be addable as one file.

## Done when

The console opens on this directory, the Docs tab explains itself, and a
project with no sidecar markdown shows these samples rather than another
repo's leftover plan.
